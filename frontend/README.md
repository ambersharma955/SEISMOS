# SEISMOS Frontend

React 18 + Vite 6 single-page app (Overview, Seismic Intelligence, Space Observation, Emergency Response).

```bash
npm install
npm run dev        # http://localhost:5173 (proxies /api and /impact-api to the backends)
npm run build      # production bundle in dist/
npm run preview    # serve dist/ locally with the same proxy
```

Requires Node.js 20.19+ or 22.12+. See `.env.example` for configuration and `../README.md` for deployment.
